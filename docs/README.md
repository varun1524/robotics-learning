## Repository conventions

- [Source package boundaries](../src/README.md)
- [Future protocol contracts](../proto/README.md)
- [Test strategy](../tests/README.md)
- [Architecture decisions](../decisions/README.md)
- [Bag recording policy](../bags/README.md)
- [Evidence policy](../evidence/README.md)

Generated bags, media, databases, maps, credentials, and evidence are ignored.
Commit only small Markdown manifests, sanitized configuration, source code, and
tests. Never commit a private key or access token.
